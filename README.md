# Iter
take a sequence f(x,y) such that we only focus on integer tuple inputs , therefore x,y belongs to Z. now we define iteration on this as if f(x_0,y) = x_1 then we evealuate f(x_1,y) next and so on . it would either loop or explode to inf thus we color the initial (x_0,y) based on which path it took, further colors are added at for 'how much time iteration steps it takes to explode' similar to mandelbrot boundary coloring smoothstep iter function. This tool generates f(x,y) using genetic algorithm to explore the state space of all possible function instead of limiting ourself to a few and see the patterns in them, which much to the suprise are complex fractal like structures, some repeating patterns, some chaotic, some blend of all. If one observe the idea deeply it is analogous (integer version) of the complex iteration in which weve got the famous mandelbrot, julia sets and the likes which we know are 2d slices of the 4d space (as integers are dim. 1 we iterate over two variables and get 1×2 dimension, so the graph is the entirity of the patterns there, similarly in the complexes which are 2 dim we iterate over all possible z in range and get a 2×2 or dim 4 pattern space.
